# AI Lead Hunter: คู่มือตั้งค่าและใช้งาน

ระบบหาลูกค้าสำหรับพนักงาน เปิดใช้ที่ **https://www.haliviq.com/staff/leads** (ใช้รหัสผ่านเดียวกับฮาวี่ฝั่งพนักงาน `STAFF_PASSWORD`)

```
หาบริษัท (Apollo หรือวางรายชื่อเว็บเอง)
   → ตรวจเว็บไซต์อัตโนมัติ (ความเร็ว, HTTPS, มือถือ, SEO, ความสดใหม่, ช่องทางติดต่อ)
   → ให้คะแนน 0-100 และเกรด A-D (กฎตายตัว + Claude ปรับ ±15 พร้อมเขียนข้อความเปิดการขาย)
   → เก็บใน Supabase
   → ส่งรายชื่อที่มีอีเมลเข้า Brevo
   → แจ้ง n8n ทุกครั้งที่มีความเคลื่อนไหว (ถ้าตั้งไว้)
```

## ไฟล์ของระบบ

| ไฟล์ | หน้าที่ |
|---|---|
| `app/staff/leads/page.tsx` | หน้า Dashboard |

| `lib/lead-hunter/apollo.ts` | ค้นบริษัทจาก Apollo |

| `supabase/lead-hunter.sql` | สร้างตารางในฐานข้อมูล (รันครั้งเดียว) |

## ตั้งค่า (ใส่ใน Vercel → Settings → Environment Variables แล้วกด Redeploy)

| ตัวแปร | จำเป็น | ได้มาจากไหน |
|---|---|---|
| `STAFF_PASSWORD` | ✅ | มีอยู่แล้ว (รหัสเดียวกับ /staff) |
| `SUPABASE_URL` | ✅ | Supabase → Project Settings → API → Project URL |
| `SUPABASE_SERVICE_ROLE_KEY` | ✅ | หน้าเดียวกัน → `service_role` key หรือ secret key (ห้ามใช้ anon key, ห้ามเปิดเผย) |
| `ANTHROPIC_API_KEY` | แนะนำ | มีอยู่แล้วถ้าแชตบอทเว็บใช้งานได้ ไม่มีก็ยังให้คะแนนได้ แต่ไม่มีบทวิเคราะห์และข้อความขาย |
| `APOLLO_API_KEY` | ไม่บังคับ | Apollo → Settings → Integrations → API (ต้องเป็นแพ็กเกจที่เปิด API) ไม่มีก็วางรายชื่อเว็บเองได้ |
| `BREVO_API_KEY` | ไม่บังคับ | มีอยู่แล้วถ้าฟอร์มติดต่อส่งเข้า Brevo |
| `BREVO_LEADS_LIST_ID` | แนะนำถ้าใช้ Brevo | สร้าง list ใหม่ชื่อเช่น "Prospects" แล้วใส่เลข ID (แยกจาก list จดหมายข่าว) |
| `BREVO_LEAD_ATTRIBUTES` | ไม่บังคับ | ใส่ `1` เพื่อส่ง COMPANY, WEBSITE, LEAD_SCORE, LEAD_GRADE ไปด้วย **ต้องสร้าง attribute ทั้ง 4 ใน Brevo ก่อน** ไม่งั้น Brevo จะปฏิเสธ |
| `N8N_WEBHOOK_URL` | ไม่บังคับ | n8n → Webhook node → Production URL |
| `N8N_WEBHOOK_SECRET` | ไม่บังคับ | ตั้งเองได้ จะถูกส่งเป็น header `x-haliviq-secret` ให้ n8n ตรวจ |
| `LEAD_MODEL` | ไม่บังคับ | เปลี่ยนรุ่น Claude ที่ใช้วิเคราะห์ (ค่าเริ่มต้นเหมือน `STAFF_MODEL`) |

### ตั้ง Supabase (ครั้งเดียว)
1. สมัครและสร้างโปรเจกต์ที่ supabase.com (แพ็กเกจฟรีพอสำหรับเริ่มต้น)
2. เปิด **SQL Editor** วางเนื้อหาไฟล์ `supabase/lead-hunter.sql` แล้วกด Run
3. คัดลอก URL และ key ไปใส่ Vercel ตามตารางด้านบน

## วิธีใช้
1. เข้า `/staff/leads` ใส่รหัสพนักงาน แถบด้านบนบอกว่าบริการไหนเชื่อมแล้ว (● เขียว) หรือยัง (○)
2. **หาบริษัท:** แท็บ "วางรายชื่อเว็บ" (บรรทัดละ 1 เว็บ) หรือแท็บ "ค้นจาก Apollo" (คีย์เวิร์ด, ประเทศ, ขนาดบริษัท) โดเมนที่มีอยู่แล้วจะไม่ถูกเพิ่มซ้ำ
3. กด **"ตรวจเว็บที่ยังไม่ตรวจ"** ระบบตรวจทีละเว็บ (เว็บละประมาณ 2-15 วินาที) กดหยุดได้
4. เรียงตามคะแนน เปิด "ดูรายละเอียด" เพื่อดูปัญหาของเว็บ บทวิเคราะห์ AI และ **ข้อความเปิดการขาย** (คัดลอกได้ ตรวจก่อนส่งทุกครั้ง)
5. ใส่หรือแก้อีเมลและชื่อผู้ติดต่อ แล้วกด **"ส่งเข้า Brevo"** เปลี่ยนสถานะตามการขาย: ใหม่ → ตรวจแล้ว → น่าสนใจ → ติดต่อแล้ว → ตอบกลับ → ปิดได้/ไม่สำเร็จ

## วิธีคิดคะแนน
- **ความต้องการ (60%)** = 100 − สุขภาพเว็บ (เว็บยิ่งมีปัญหา ยิ่งมีโอกาสขาย)
- **ความเหมาะสม (40%)** = ขนาดบริษัท 5-200 คนได้คะแนนสูงสุด, มีอีเมลติดต่อ, ใช้ Wix/Squarespace (มีโอกาสย้ายมาทำเว็บจริง), ไม่มีระบบวัดผล ส่วนเว็บที่เปิดไม่ได้จะถูกหักคะแนน
- **Claude ปรับ ±15** พร้อมเหตุผล เช่น ลดคะแนนถ้าเป็นบริษัทใหญ่มากหรือเป็นเอเจนซีคู่แข่ง
- เกรด: A ≥ 75, B ≥ 55, C ≥ 35, D ต่ำกว่านั้น

## เหตุการณ์ที่ส่งไป n8n
POST JSON `{ event, at, data }` โดย `event` เป็นหนึ่งใน:
`leads.imported` (มีรายชื่อใหม่), `lead.audited` (ตรวจเสร็จ มีคะแนน ปัญหา และข้อความขาย), `lead.pushed` (ส่งเข้า Brevo แล้ว), `lead.status` (เปลี่ยนสถานะ)
ตัวอย่างการใช้ใน n8n: ถ้าเกรด A ให้แจ้ง LINE/Slack, สร้างงานใน CRM หรือเริ่มลำดับอีเมลอัตโนมัติ

## ข้อจำกัดที่ควรรู้
- การตรวจเว็บดูแค่หน้าแรก ด้วยการอ่าน HTML ไม่ได้รันเบราว์เซอร์จริง เว็บที่สร้างหน้าด้วย JavaScript ทั้งหมดอาจถูกมองว่าเนื้อหาน้อย
- Apollo ค้นได้เฉพาะข้อมูลบริษัท ยังไม่ดึงอีเมลของคน (การดึงอีเมลใช้เครดิต Apollo) อีเมลจึงมาจากที่ระบบเจอในเว็บไซต์ หรือพนักงานกรอกเอง
- ส่งอีเมลขายจริงต้องทำใน Brevo (แคมเปญหรือ automation) ระบบนี้ไม่ส่งอีเมลหาลูกค้าเอง
- ส่งอีเมลขายต้องทำตาม PDPA (ไทย) และ CAN-SPAM (สหรัฐ) มีช่องทางยกเลิกรับ และใช้เฉพาะอีเมลธุรกิจที่เปิดเผยต่อสาธารณะ
